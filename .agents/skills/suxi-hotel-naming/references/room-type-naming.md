## 推荐结构

优先使用：`一个最强且真实的卖点 + 标准房型`。

可用结构示例：

- `投影 + 大床房` → 投影大床房
- `浴缸 + 大床房` → 浴缸大床房
- `观山 + 双床房` → 观山双床房
- `亲子主题 + 家庭房` → 亲子家庭房
- `诗意前缀 + 已确认景观 + 标准房型` → 云栖·观山大床房

当卖点过多时，只保留最影响选择的 1–2 个；其他信息放入房型卖点描述，不塞进名称。

## 可核验分类

- 结构：套房、非套房、一居、二居、二室二厅、Loft、复式。
- 床型：大床、超大床、双床、圆床、榻榻米。
- 景观：山景、海景、湖景、园景、地标景观、无特殊景观。
- 设施：投影、浴缸、电竞、麻将、阳台；以及无特殊设施。
- 风格：民族、古典、日式、田园、北欧；以及无特殊风格。
- 面积：15–20、20–25、25–30、30–35㎡等区间；面积必须来自真实字段。
- 位置：近电梯、近消防通道、临街、低楼层、高楼层；位置词可能影响偏好，不能只当正向卖点。
- 业态：商务酒店/酒店公寓、度假酒店/民宿/客栈。

## 词汇层级

以下词仅用于建立同店层级，不能替代实际权益：

- 价值型：特惠、经济、普通、惠选。
- 中档型：精选、精致、优选、舒适、雅致、温馨、静谧。
- 中高档：高级、商务、商旅、优享、悠享。
- 高档型：豪华、轻奢、甄选。
- 顶级型：行政、尊享、至尊、臻品、奢华。

同一门店应建立单向、可解释的层级，避免“雅致、精选、臻选、尊享”彼此没有权益差异却同时存在。

## 高意图信息与低信息词

在真实存在时，通常更能帮助用户快速判断的词包括：私汤/泡池、影视/观影、智能/科技、露台/花园阳台、棋牌、亲子、180°/270°/360°观景、舒睡/静眠、庭院/花园。

单独使用“雅致、悦享、臻选、轻奢”等泛化形容词，信息量较低。它们可以辅助层级和语气，但不应盖过床型、结构和核心卖点。

## 淘汰规则

- 没有标准房型后缀的纯诗意名称。
- 同义词连续堆叠，例如“臻选尊享奢华”。
- 把负向或中性位置事实包装成无条件正向卖点。
- 名称暗示权益，但详情页和现场无法兑现。
- 同店两个名称不同，实际房型和权益完全相同。
