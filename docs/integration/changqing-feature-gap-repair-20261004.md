## 关键口径

- 保本差额是收入与人工设定保本收入的差额，不等同于 GOP、净利润、酒店现金流或投资人实际回本。现有投资测算与现金回收账本继续使用其原口径。
- OTA 预订数据仅支持对应渠道结论。整店收入汇总只接纳带来源引用、合适日期及明确整店范围的事实；人工确认仍是人工证据，不等同于独立采集验证。
- 周报可自动预填已有数据，但缺失或未验证内容继续可见，人工结论和审核状态分别保存。
- 页面查询切换门店、日期、固定时间或监测期限后会丢弃旧响应，释放加载状态；周报改日期后不能导出旧日期报告。
- 查看权限账号可以重选匹配的本地素材并导出已存制作单，服务器保存仍要求执行权限。媒体预播放中取消会结束制作并释放媒体与轨道，迟到的播放响应不会重新启动录制。
- 保存采用版本比较和幂等请求，返回保存 ID、内容摘要及同范围回读证据。没有 OTA/PMS 写入、平台申诉、发布、财务付款或自动审批。
