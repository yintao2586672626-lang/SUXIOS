## 主要修复

1. **数据与知识归属**：知识导入、引用和版本变更校验酒店、创建者、源单元、当前版本及摘要，保存后独立回读；分析只使用正向核验的最终日事实，并独立读取来源归属。混合平台/指标、重复日粒度、缺失身份或归属不符时，总额保持未知，停止趋势和排名并显示原因。
2. **保存与旧数据兼容**：修复完整测试中才出现的数据库字段缓存污染，覆盖不同连接及表结构切换。旧 Ctrip `visitor_count` 只在明确 UV 定义下兼容；新记录统一 `unique_users`，不改写原回执。
3. **页面请求与恢复**：旧酒店、日期、页面或登录态的 PMS 请求不能覆盖当前结果或解除新请求的加载状态；同范围已确认知识/日报快照在刷新失败时保留并显示错误，未确认或跨范围旧结果不伪装成成功。
4. **运营链**：保留原任务精确回读和回跳，补齐移动端执行证据入口及审批日期警告；过期批准在首次确认和提交前均阻断，驳回仍可用。任务轮询失败保留原编号、待核验状态及可证实的部分结果，缺失数量不补 0；仅有 `success` 状态不能替代独立回读验证。
5. **历史记录与前端整合**：美团历史数据支持真实日期范围、渠道详情和带范围元数据的导出。导出使用确认的已加载查询，拒绝混入其他酒店/日期行。修复启动组件作用域和缺失工具导出；构建源码、模板与产物保持一致。原有体积及热点上限不放宽。
6. **顾问依赖与文件路径**：经营顾问在创建前等待可调用的证据导航组件，加载失败或接口类型错误时显示可重试状态，缓存组件也遵循相同顺序。修补 `league/flysystem` 的畸形 UTF-8 路径校验漏洞，仅从 3.34.0 升至最小修补版本 3.35.3；其余 51 个依赖及审计要求保持。
7. **正式知识共享与带教摘录**：知识列表、详情和引用复用相同的读取策略。已批准的同酒店正式 SOP 可被本酒店其他成员引用，连续审批产生的异作者当前版本也可用；私有资料仍校验作者、酒店和租户，共享读取不授予修改权限。带教计划每个引用只保存最多 4KiB 摘录、固定版本与内容指纹，单份 JSON 上限 16KiB，最多 8 份合计 128KiB；正文保留在知识源。截断在页面标为“节选”，编辑保留显式片段选择，旧计划仍可读取。
8. **月度统计与知识种子**：月度累计、覆盖和导出仅使用已提交日报，草稿、缺失或格式错误的状态不能补齐缺报日；全草稿月份指标保持未知。追加修正迁移，只恢复原全局种子缺失的当前版本指针，不覆盖非零指针，不修改历史迁移、源内容或摘要。
9. **跨年节日提醒**：2026 年已核验的完整放假区间保留。未核验完整年表的年份，只在现有提醒窗口内使用法规明确的公历日期事实，完整放假、调休及未知农历节日继续标为待核验；非法日期不会借用今天。[现行放假办法](https://www.gov.cn/zhengce/content/202411/content_6986380.htm)、[2026 年官方安排](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)
10. **请求日期与失败分类**：携程手动采集及概览在默认日期之前严格核验原始日期，拒绝相对日期、时间戳、溢出日期和附加文本，保留明确的日历日期格式兼容。AI 日报 latest 的非法日期返回 422，真实读取故障仍返回 503，合法空结果继续显示待生成。
11. **带教有效状态复核**：创建带教计划先锁定同租户、酒店、经理的原案例，再读取实际有效状态和最新事实。锁等待窗口内已作废、删除、换范围或修正日期的案例不能按旧快照创建计划；SQLite 确定性反例验证状态窗口，不作为 MySQL 真实并发锁证明。
12. **指标选择与页面恢复**：数据分析新增独立于日/周/月分组的指标口径选择；只有当前授权范围内的可信指标可选，分析与明细按同一精确指标查询并回显范围。混合口径保持阻断，不自动选择；切换酒店、日期、登录态或指标后，旧请求不能覆盖当前结果。并行读取中，一个成功结果不能抹去另一个失败提示，旧快照继续标明原加载范围。

13. **知识引用权限与回显**：续查新增的 3 个知识问题已修复。资料勾选采用真实的读取、当前版本及摘要策略，正式共享资料可选但不授予编辑权；来源和保存使用认证身份的管理员及租户上下文，拒绝表单伪造与跨范围来源。参考稿写入归入现有知识管理能力和 20 次/小时限流，只有阅读权限时页面禁用保存入口并提示原因。脱敏仅保留参考 SOP 的五个固定字段绑定，原文及摘要精确回显，任意路径与已剥离的敏感索引不能重新出现。
14. **日报表前缀兼容**：续查的日报读取问题已修复。租户谓词、表和字段检查、执行意图查询统一解析实际表名；缓存区分连接、数据库及物理表。覆盖只有前缀表、两种表结构并存、切换连接与前缀、旧租户值、酒店转移及保存回读。真实日报读取故障仍返回 503；只有执行证据读取失败时，日报保持可读并明确显示工作流阻塞。
