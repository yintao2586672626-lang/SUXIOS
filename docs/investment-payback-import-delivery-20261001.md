# 投资回本表格与图片导入 — 本地验收

目标：在投资回本页上传文件、核对识别结果、人工确认入账，并能重新打开读回。原项目页面不刷新、不关闭；真实项目与资金记录不写入测试数据。

## 用户操作

1. 页头“导入表格 / 图片”。支持 XLSX、XLS、CSV、PNG、JPEG、WebP，也可粘贴 Excel 单元格或截图。
2. 选择“新建项目累计余额”或“项目资金明细”。从项目详情打开时预选该项目；归档项目不可选择。
3. 核对工作表、表头、对应列和金额单位。多人分红表需选择本人金额列；缺年日期必须填写原表年份；未识别类型需选择投入或收回。
4. 生成可编辑预览，修正错误或取消行，勾选核对确认后入账。每次确认最多 200 行。
5. 导入后刷新列表或原项目详情并显示确认数量；再次打开金额与来源一致。

## 数据与失败行为

- 预览不写账；图片采用本机 Windows 中文 OCR，不使用外部识别服务。原图 / 原文和候选金额可核对，来源保持“未独立核验”。
- 后端最多 10 MB、500 行、32 列、10 个工作表；压缩包及图像处理有界。Excel 公式只保留原文，不计算。月份保持月份，不补造日或年。
- 全角数字、中文标点、数字间小数点候选在预览中规范化；分币金额精确保留，不把缺失补成零。
- 确认复用原有租户、项目及酒店权限、保存和审计接口。任一行失败整批回滚；已有同项目主体或相同有效资金明细拒绝重复导入。
- 相同请求、相同内容重试读回已有结果；变更内容不得复用旧请求。未确认数量或保存失败保留预览和编辑内容。
- 原文件名、SHA256、方式与原行号保存到来源字段。表格显示简明文件名，完整来源仍可查看。不会覆盖已有项目累计余额或删除真实资金记录。

## 两轮自检与修复（最新验收）

用户将“五次”改为“两次”，本次完成两轮不同检查，不重复执行五轮。检查范围仍为投资回本导入及直接台账、页面依赖；原用户页面不刷新、不导航、不关闭，真实账务没有测试写入。

第一轮检查识别与数据口径，复现后修复：

- 单元格明确写“元”时优先使用单元格单位，不再因表头“万元”额外乘一万；单元格明确写“万元”同样保留其单位。
- Excel 粘贴中的引号、双引号、单元格内制表符与换行按一个单元格读取；不完整引号明确失败。备注预览改为多行编辑，保留完整内容。
- 合计行只按项目名称或日期所在列判断，备注、投资人写“合计”不再误删正常行。
- XLSX/XLS 仅显示年份、无年份、仅时间、年份加时间、仅星期时保留来源显示并提示核对，不补造完整日期。完整月份仍保持月精度；AM/PM 不被误当月份。

第二轮检查保存、恢复与页面操作，复现后修复：

- 文件选择器读取后清空选择值，识别失败能再次选择同一个文件。
- 详情页导入时改选另一项目，保存后打开实际入账项目，不再回显进入导入前的项目。组件离开后的迟到保存响应不触发旧页面刷新。
- 导入幂等键从超过50字符改为47字符，散列包含完整租户、用户和请求UUID；兼容旧长键的只读重放。
- 不把时间戳整数写入 DATETIME，使用数据库默认时间。只读本机 `information_schema` 确认 `hotelx.system_config` 当前为 VARCHAR(50) 和两个 DATETIME DEFAULT CURRENT_TIMESTAMP。
- 项目锁后的重复明细检查采用 `FOR UPDATE` 当前读，避免 REPEATABLE READ 下锁前旧快照漏掉先提交记录。
