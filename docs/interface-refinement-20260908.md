# 界面优化与验收记录 · 2026-09-08

## 本轮结果与边界

本轮把登录后的外壳、经营首页和任务页的主要视觉问题落到代码中，并建立可复用的设计规范。范围包括导航、顶栏、警示条、页面留白、事实与待办面板、状态、折叠参考区和任务操作；没有改经营事实、OTA/PMS 数据、账号或权限，也没有执行经营审批。

主方向：深绿导航、明亮主内容、克制的金色强调、统一字号与间距，让门店、业务日期、事实与待办先被看见。设计依据与具体值在 [界面设计规范](../rules/interface-design-standard.md)。

## 已处理的具体问题

| 原问题 | 最终处理 |
| --- | --- |
| 深色顶栏、米色画布、渐变装饰和多层卡片同时占据注意力 | 白色顶栏、浅中性底色；清除主内容与页面顶部装饰伪元素；取消首页外层容器边框和重复内边距 |
| 操作普遍强调为金色 | 深绿主操作，描边次操作，历史记录用文字链接；保留错误、缺失和警告语义 |
| 同一任务在待办与异动分组重复出现 | compact 首页只渲染一次任务，异动汇总收敛为一行；原始对象、点击和刷新行为保留 |
| 时间区、回读时间、小号提示与橙色状态对比不足 | 调整实际文字颜色；检查完整延迟样式加载后仍可读 |
| 深绿侧栏焦点不显眼、旧子菜单缺少键盘入口 | 浅金内侧焦点线，补齐子菜单的 Tab 与 Enter/Space 操作；日期控件的焦点覆盖旧规则 |
| 首页直接显示 `operator_attested_only` | 显示“只有人工确认，仍需补充来源证据”，原始代码保留在提示属性，不改变证据状态 |
| 门店身份不匹配被拦截后，卡片仍标题为“暂无事实” | 统一到 error 展示，明确读取失败，不显示其他酒店的指标 |
| 任务页“我的待办”选中时出现白底白字 | 对现有深绿主操作补上页面级视觉样式，保留 aria-pressed 状态 |
| 高级管理折叠导致源模板提取吃掉外层闭合标签 | 仅该目标组件按 Vue AST 的元素边界提取，保留外层 details、经营记忆及加载/错误兄弟节点 |
| 首页独立样式变更后可能继续使用旧 URL | 官方样式构建自动同步 SHA-256 版本，校验命令拒绝过期哈希；不手改压缩产物 |
| 原视觉冒烟可能过早截屏、报告所有页面已测 | 按本轮目标页面收敛测试，核对实际被测数量及加载后的状态 |

## 验收方法

- 真实登录浏览器：本机 127.0.0.1:8080，实际页面宽度约 1116px；检查首页、门店切换与手动刷新、历史日期入口、待办只显示一份、任务页按钮、参考区与经营记录折叠。
- 独立模拟浏览器：无真实账号资料，API 全部拦截为明确的视觉夹具。使用 1440×900、390×844、320×844 验证布局；该证据不代表真实数据、账号权限或生产功能验收。
- 行为回归：compact 渲染与去重、读取失败与空状态、酒店身份、历史日期精确回读边界、模板提取边界。
- 构建：模板、入口、样式、helper 和公共入口校验；实际服务的资源哈希另行核对。
