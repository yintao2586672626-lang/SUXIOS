# 酒店投资回本主线交付

以投资人实际出资、实际收回为口径，提供项目台账、累计余额、资金明细、回本进度和回本后盈余。营业额、账面利润、计划金额、未来明细不作为当前实收；期初已覆盖的历史金额不重复叠加。未填投入保留待录入状态。

功能包括：

- 项目新建、编辑、归档，按截至日查看累计投入、净收回与未回本缺口；已覆盖项目盈余不抵扣其他项目缺口。
- 投入、收回、退款 / 冲回记录，版本校验、幂等保存、作废、管理员删除及变更记录。
- 卡片拖动与键盘排序，自动保存并核对读取；台账筛选、搜索、排序和项目比较。
- Excel / CSV、表格粘贴和本机图片识别，预览列映射、来源行、单位、日期、重复候选、选中行金额影响，再确认整批入账。图片识别仅在具备本机 OCR 运行条件时可用；缺少识别能力会明确报错。
- 基础经营情景测算、年度资金规划、多方案比较、保存与历史版本；测算假设与真实回本账务分开。

本轮修复了切换统计日期时的旧请求覆盖、导入确认忽略排除行、文本计划标识可能计入实收的问题，并补齐正式模板注册，避免构建同步遗漏投资回本页面。
