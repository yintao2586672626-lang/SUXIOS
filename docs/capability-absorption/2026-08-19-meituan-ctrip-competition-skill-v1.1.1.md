## 吸收的业务合同

1. 携程平台转化率保留为来源值；`订单量 / APP详情页访客量 × 100%` 单独
   形成派生预订转化率，缺失分母时保持 `null`。
2. 携程 ARI/SCI 只读取平台字段，不反推私有算法；现有原始行若返回
   `ari`、`sci`、`ctripRatingall` 等明确字段，会进入来源事实层。
3. 美团当前生产来源只有排名摘要时，仍可保留原有有界排名研判，但完整商圈
   状态明确为 `rank_summary_only`，入住、销售、流量、转化四榜逐项显示未采集。
4. 美团销售与入住是不同时间窗口，差额不是取消率；没有真实取消字段时不
   产生取消结论。
5. 证据合同只验证目标日快照；没有另行验证可比历史序列时，不输出环比、
   同比、趋势或已验证价格弹性。
6. 每个平台保存 `analysis_scope`、`full_circle_ready`、完整度计数、逐项证据、
   来源引用和语义边界；页面摘要和同一 bundle 的 HTML 导出都直接回显。
7. 新完整度不改写既有 `quality.decision_eligible`，避免把原本可做的有界研判
   错误阻断；“可人工研判”与“完整商圈证据齐全”作为两种成熟度分别报告。

## 明确不吸收

- 不安装附件 Skill，不把商业页数、Word/图表门禁伪装成宿析OS界面版能力。
- 不把携程字段混入美团，也不把 OTA 渠道快照外推成全酒店经营事实。
- 不启动 Web 请求中的 Python/LibreOffice 子进程，不引入附件依赖。
- 不自动改价、投放、发布内容或执行任何外部写入。
- 不把单期排名差解释为因果、趋势、取消率或已证明的价格弹性。
