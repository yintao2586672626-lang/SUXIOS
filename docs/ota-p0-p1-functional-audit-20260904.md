## 已修复的问题

| 级别 / 编号 | 用户可见影响与复现 | 修复 |
|---|---|---|
| P1-01 酒店线上查看权限遗漏 | 账号只有甲酒店线上查看权限，但普通酒店可见列表还含乙酒店；无酒店筛选时，数据源、同步任务和同步日志列表仍返回乙酒店记录。同租户内按酒店能力越权，不是已证实跨租户泄露。 | `PlatformDataPersistenceConcern`三个只读列表按每家酒店的`can_view_online_data`再过滤；保留租户边界、超管范围与正常允许酒店，不改变采集/删除权限。 |
| P1-02 美团旧请求回填新酒店/账号 | A账号/酒店901发出订单请求，切到B账号/酒店902并清屏，旧响应仍写入当前订单结果并通知成功。流量、订单、CSV导入、广告同类入口均受影响。 | 共用请求归属守卫，核对账号会话和美团酒店epoch；旧成功、失败、异常及后台受理结果不回填、不通知、不触发刷新。重置释放旧loading，旧finally不清除新请求loading。 |
| P1-03 测试数据进入经营快析 | 隔离样例4笔正常订单+99笔显式测试订单被汇总为103；仅测试数据也可生成订单指标，美团测试流向可呈现流失信号。 | 双平台快析在规范化/汇总前排除`explicit_test_fixture`；指标缺失不补0，明确显示“测试样例已排除”，返回排除行数。测试记录仍保存在历史中，不删除，不按酒店名字或人工导入方式猜测是否测试。 |
