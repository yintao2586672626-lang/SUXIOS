## 本次复核新增修正

1. 从首页进入任务页时，完整模板重新挂载可能不触发初始页观察器。认证初始化后显式恢复任务页读取；原先可复现的页面等待超时已消失。
2. 当前日期存在未核验行时，历史查询曾返回当前日，随后被前端排除，隐藏了更早的入口。服务端现在直接查询更早日期，并以含当前日记录的测试覆盖该场景。
3. 视觉冒烟超时现在记录页面、加载状态及样式就绪情况，便于判断真实启动失败；不清除未知错误来获得通过结果。
4. 冷启动截图暴露了首页关键样式被延迟加载的问题。首页独立样式改为启动阶段加载，并增加真实标题字号和工具栏布局的断言；无溢出检查不能替代实际外观复核。
