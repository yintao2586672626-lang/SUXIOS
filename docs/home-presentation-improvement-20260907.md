# 首页展示提升 · 2026-09-07

目标：让使用者打开首页后，先确认门店和业务日期，再看到经营概况与今日待办；数据依据和处理记录保持可查。

## 本轮方向与验收

| 方向 | 实现 | 验收目标 |
| --- | --- | --- |
| 明确查看范围 | 顶部门店与经营事实日期控件 | 桌面首屏可见，仍使用原有查询状态与刷新入口 |
| 建立信息主次 | 左侧经营概览，右侧今日待办与异常 | 桌面并排；窄屏按阅读顺序排列，无横向溢出 |
| 提高数据可读性 | PMS 住宿房费、入住率与 OTA 订单、房晚分组展示 | 复用原值、原来源、原状态；零与缺失保持不同 |
| 压缩重复说明 | 缺失状态保留一段说明和数据来源入口 | 错误与加载可见；不把读取失败写成没有数据或没有任务 |
| 保留完整依据 | 完整指标、周计划、经营记录按需展开 | 来源、同日对账和核验信息仍在原组件中；不自动执行经营动作 |
| 统一品牌层次 | 深绿主操作、浅色数据面板、克制金色、统一间距 | 正文可读，按钮可聚焦，关键数值完整展示 |

范围仅限首页展示及其现有呈现组件。数据采集、指标计算、接口、权限和经营动作未扩展；登录页及其他业务页不进行全局换肤。
