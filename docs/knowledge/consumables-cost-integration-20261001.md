# 易耗品成本学习与本地功能接入

更新日期：2026-10-01。范围为经营情景假设；不代表真实酒店耗用或线上部署。

## 已接入的功能

入口：投资回本台账 → 打开项目 → 经营情景测算 → 易耗品成本明细。

- 每个用品保存名称、启用状态、包价格、包净含量、单位、用量、用量基准、事件次数/已售间夜、来源及基准日期。
- 支持件、mL、g；净含量和用量使用同一单位。每客夜或每次清洁需提供事件/已售间夜换算假设。
- 公式：`包价格 / 包净含量 × 每基准用量 × 事件次数每已售间夜`。
- 默认仍使用原手填汇总；明确选择采用明细后，以用品合计加其他变动成本替代原单位经营成本。手填值保留。
- 明细只适用于按已售间夜或固定加变动口径；租金、固定年成本、管理费、折旧分别计算，避免重复。
- 价格、净含量、用量或换算未知时不形成可采用合计；显式0保留，包净含量必须大于0。空表、全停用或全未知不能显示完整成本0。
- 停用行保留资料并排除；利润、现金代理、保本与敏感性计算使用相同有效成本。
- 保存使用既有项目审计快照，回读核对输入、结果、摘要与版本；编辑后旧结果失效。旧快照保留，重算才升级模型。
- CSV使用同一结果快照，并包含采用方式、明细与来源；测算不写实际资金台账。

## 学习来源与边界

Joydo/JHIRA的成本学习包已覆盖采购与耗用、成本分母、成本采用联动；其他包涵盖现金流与回本、来源完整性、融资偿债、合同边界、OTA比较、报告快照与GEO证据。

新增计量方法参考细化了包装与稀释量纲、用量样本标定、事件分母转换、损耗原因证据。参见 [计量方法资料](consumables-measurement-20261001/README.md)。

所有外部知识保持 reference_only / absorption_candidate；网站示例的价格、80%/20%用率与结果不作酒店默认值。浓缩液、密度、损耗率、库存估价及财税政策没有足够资料时留待核实；本功能不执行采购、盘点调整、报损或经营动作。
