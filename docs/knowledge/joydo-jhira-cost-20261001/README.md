# 酒店成本深度学习与吸纳候选

本次完成可见成本模块的机制拆解、条件算术回放、现有情景计算器映射与本地知识入库。材料为 `reference_only / absorption_candidate`，不含当前酒店事实，不允许直接用于调价、经营任务或自动审批。源站成本切换传导未通过，完整成本标准库未能访问；正式产品能力集成尚未完成。

## 最值得吸纳的成本链

**采购配置 → 同期间耗用 → 成本范围与单位 → 选定测算成本 → 利润/保本/现金 → 保存与复盘。** 每一步保留来源、期间、计量单位、是否纳入和缺失状态。采购花了多少钱、房内配置值多少钱、这个月实际耗用了多少钱、测算采用多少元/间夜，是四个不同问题。

来源同时出现用品 61.64、49.17 和 5.78。61.64 是配置合计；49.17 可由 `(61.64−0.24)×80% + 0.24×20% = 49.168` 四舍五入得到，但系数没有实耗证据；5.78 才是本次快速测算读到的采用值。不能将三者互换，也不能把采购一瓶的单价直接作为每间夜耗用。

## 六组可复用规则

### 1. 采购、耗用、现金和资本分开

物料实耗先以统一的基础单位做库存平衡：期初 + 入库采购 + 调入 − 期末 − 调出 − 退货 − 单独登记的报损 = 经营耗用数量。采购入库与实际付款可跨期；报损单独呈现，不能同时计入耗用和损失。缺盘点或单位换算时输出待核对，而非“真实耗用”。金额计价方法、税费与运费按酒店已确认政策另行确定。

用品与清洁剂通常按耗用确认；布草采购、家具设备、装修和押金需要分别标识费用、资本投入或可退资金。折旧影响利润但不能重复当期现金流出；贷款本金与利息不能混成同一种经营费用。此处是模型边界，未替任何酒店确定会计政策。[IAS 2 通用参考](https://www.ifrs.org/issued-standards/list-of-standards/ias-2-inventories/)

### 2. 用量必须带基准和周期

| 对象 | 可接受的计算基准 | 必须补齐的证据 |
|---|---|---|
| 一次性用品 | 件/已售间夜、件/客次或件/退房清扫 | 配置量与实际取用量，续住/退房规则 |
| 大瓶洗护/清洁剂 | 元/毫升 × 毫升/客夜或清扫次数 | 容量、每次用量、客夜/间夜换算、损耗 |
| 洗涤 | 元/件 × 件/清扫或已售间夜 | 续住换洗政策、外包结算期间 |
| 早餐 | 元/份 × 实际供餐份数 | 房价是否含早、用餐率、员工餐范围 |
| 人工与水电 | 固定底座 + 业务量增量 | 固定工资/基础能耗与外包清扫/增量能耗分开 |

“每间房两套”不等于每个已售间夜都耗用两套；每客夜成本不能在缺客夜数时直接乘已售间夜。自编回放中的 500ml、20 元、15ml 和 1.4 客/已售间夜仅用于验证单位转换，不是来源标准或宿析默认值。

### 3. 统一分母与收入范围

同期间可售间夜记为 A、已售间夜为 Q、同口径房费收入为 R。`入住率=Q/A`，`ADR=R/Q`，`RevPAR=R/A`。来源使用到手房价，本次相应使用净价口径收入。[CoStar/STR 定义参考](https://www.costar.com/products/str-benchmark/resources/data-insights-blog/what-revenue-available-room-revpar-and-how)

对同一组费用 C，`C/R = (C/A)/(R/A) = (C/Q)/(R/Q)`。可售成本与已售成本可以并列展示，但不能交叉除。只有分母存在且大于零才输出比率；缺收入或零收入显示无有效分母。停用房、免费房、日间房和房量变更需按酒店已确认业务规则确定 A/Q，不默认永远“房数×天数”。若成本包含餐饮等其他业务，应另用同范围收入，不能仍除纯客房收入。

外部示例 C=118,598、R=156,000：正确同范围成本率为 **76.02%**；C/A=79.07，除以净价口径 RevPAR 104，仍为76.02%。页面88.61可由 `92,000/1,500+27.28` 匹配，再除104得到85.21%。这是数值吻合支持的公式推断，未读取上游算法；它将按可售间夜分摊的固定费用与每已售间夜变动费用直接相加，不能当成本率通用定义。

### 4. 防止重复扣款，固定/变动各有适用量

在来源简化模型中，`Q=A×入住率`、`R=Q×净ADR`、`C=F+Q×v`，经营利润为R−C。净ADR已扣平台佣金，不能再次扣佣金；若采用成交价，则渠道费用另算，并分别标明渠道、退款与补贴范围。混合渠道要按渠道收入和费率计算，不能对全酒店套一个OTA费率。

租金、管理费、折旧若已有独立字段，聚合经营成本需排除已单列费用。来源月固定92,000含租金50,000；映射宿析时，非租金固定成本为42,000×12，租金按50间×1,000元/间/月单列。将92,000×12与独立租金同时加入会重复计费。水电、人工允许固定与变动拆分，不能仅按费用名称一概归类。

### 5. 成本变化必须传导，缺证不能输出完整回本

| 条件回放（外部示例） | 原采用用品5.78 | 假定精算49.168也是每已售间夜 |
|---|---:|---:|
| 每已售间夜总变动成本 | 27.28 | 70.668 |
| 月总成本 | 118,598.00 | 160,901.30 |
| 简化经营利润 | 37,402.00 | −4,901.30 |
| 保本入住率 | 46.21% | 68.66% |
| 300万元/恒定年利润的简化回本 | 6.68年 | 非正现金下无正有限回本 |

右栏是**条件敏感性**，不代表精算49.168已证实为每间夜实耗；左栏利润也不是完整税后可分配现金。成本差43.388×975=42,303.30，足以改变盈亏，所以采用值和基准不明会直接改变经营判断。

保本率为 `F/[A×(净ADR−v)]`，贡献非正时无有效解；结果超过100%显示条件不可达。目标回本还需要投资额、税费、融资、资本维护和营运资金等完整现金范围，不可直接用带缺口利润给出确定回本结论。源站“安全边际53.79%”数值吻合100%−保本率，而当前65%与保本46.21%的差是18.79个百分点；指标语义未确认，不能据此套风险阈值。

### 6. 标准、实际、选定值与复盘闭环

成本标准应带酒店/适用房型、物料基础单位、价格生效日、耗用假设、供应商或凭证来源、版本和批准状态。标准不等于实耗，预算不等于实际。缺细项时显示未建立分解；明确零需要有输入依据。停用行保留并排除，未知行使总量为部分已知，不将空行折成零。

选定成本须显示标准或精算、基准、纳入范围和有效预览版本。切换后总成本、利润、现金代理、保本、敏感性及报告一同重算；旧预览失效，保存后按同版本精确回读。本次来源勾选变化未证明这一链通过。

复盘先把预算与实际都换成相同期间、物料、计价和业务量基准，再拆采购价格差异、单位耗用差异、业务量变化及损耗；差异归因还需领用/盘点/价格证据，不能由相关性直接判定员工浪费。成本优化同时保留客诉、卫生、退房返工、复购等服务约束，不能只看成本最低。
