## 影响成本的关键区别

- 洗发水、沐浴露、护发素的较高档从锁盖大瓶变为小瓶；金额变小不证明单位耗用更便宜，缺净含量不能直接比较每mL或每间夜。
- D23通用建议“补充液20kg桶装150-220”不证明每个液体SKU同价；确认人民币整桶净料价后才可条件换算7.5-11元/kg，未知密度不换mL。
- C31“50G卷纸”为规格而非50元。抽纸、卷纸、垃圾袋缺完整计价包装/箱内数量；单卷或单袋克重不能替代报价包装数量。
- 19个“可不配置”、2个“根据酒店配置”及1个规格单元不属于完整数值报价。可选配置不等于免费0；A/B款不自动同时投放。
- 区间、上限、下限和“左右”分别保留，不取中点或补未知端点。币种、税费、运费、起订量和有效期未明确时继续标未知。
