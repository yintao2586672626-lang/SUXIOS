字段、函数和核心补充合计 **31 条审查记录**，包含重复佐证，不等于31个独立已复现故障。全部记录同时保存在知识单元197的 `source_material_findings` 中。下表合并重复项，但没有丢弃审查记录。

| 疑点组 | 证据与影响 | 吸纳方式 |
|---|---|---|
| 用品数量、单位和折算 | 17项缺计量/期间；白糖×0.2，其余×0.8 | 作为假设和反例，不叫实际领用或实耗 |
| 预设成本与有效零值 | 佣金18、洗涤6.5等fallback；有效零与缺失易混 | 明确null/unknown/0，引用需人工确认与来源 |

## 已落实的代码修复

`FeasibilityReportService::hasHumanReviewApproval()` 原来匹配肯定词子串，导致“未通过”“不同意”“not approved”也被识别成通过。现在只接受明确肯定状态和完整肯定历史表达，并保留布尔值及嵌套状态键兼容。普通备注、待审核、混合否定和未知文本不会变成批准。

修改前聚焦反例：3测试、59断言、2失败。修改后：3测试、105断言通过；完整可研组26测试/293断言、直接相关投资决策组9测试/130断言通过，合计35测试/423断言。本修复只影响既有可研 `manual_review.passed`，不新增自动审批或经营授权。
