# 易耗品采购参考融入经营测算

本次把2026-10-01吸纳的采购价目资料接入既有“投资回本 → 项目 → 经营测算与情景分析 → 易耗品明细”入口。来源仍是采购推荐参考；新增能力是选型、引用、待确认明细、情景采用、保存回读与导出，不是采购或库存业务。

## 使用路径

1. 打开本项目的经营测算，展开“采购价目参考”，明确选择一个品类和一个档位。系统展示原档位内容、来源单元格、对应配置建议及解释限制，不按酒店房价自动分档。
2. 点击“添加待确认明细”。名称与来源引用带入；价格、包装数量、计量单位、用量和日期保持空。原区间不会取中点，“可不配置”不会填成免费0。
3. 填写本方案采用的准确包装价格、同单位包装数量、每基准耗用量、适用的客夜或清洁事件换算，以及参数来源和本方案价格基准日。
4. 主动确认本方案的价格、包装单位和用量。确认只作用于本方案假设，源资料保持reference_only，源报价日期仍未知。修改这些参数会取消原确认。
5. 选择按明细采用经营成本并预览。未确认或关键输入缺失时，成本合计、下游年度结果和盈亏平衡保持未明确；选择原手填汇总时仍采用既有汇总输入。
6. 保存后通过原接口精确回读。重新打开可编辑参数、查看原引用与确认状态，CSV同时保留所选原档位内容、来源单元格、文件指纹、假设价格及确认状态。

## 深化后的语义

- 报价目录、配置建议、已选择的来源引用、用户输入的本方案价格、实际酒店成本是不同对象。每个对象保持自己的来源和日期，不因点击确认合并成经营事实。
- 同一原表中的大瓶、小瓶、补充液、纸品、袋品可能有不同计价包装。只有确认同单位净量与实际用量后，才计算`包装价格 ÷ 包装数量 × 用量 × 事件换算`。
- 牙具A/B具体关系保留未知，拖鞋A/B按原布局建议显示；不自动同时投放。每条明细可单独停用，停用保留编辑内容及引用。
- 价格区间、上下限、左右、可不配置及规格原样显示。所选原报价永远不直接参与成本算式；算式仅使用明细中输入并确认的准确假设值。
- 原文件、255个源单元格、27品项×5档内容、综合知识条目及5处解释修订均保留。知识入库与本次功能接入分别有证据。

## 实现边界与恢复

- 新目录读取接口位于本项目范围：`GET /api/investment-payback/projects/:id/scenario/consumables-reference`，复用既有租户、酒店和investment.simulate权限。
- 服务端校验固定来源指纹，并根据catalog/item/tier身份重建引用快照；客户端传来的报价文案、质量或来源声明不能改写规范引用。
- 来源缺失或指纹不匹配返回不可用状态；页面显示失败及重试，不使用空成功或旧项目目录替代。切换项目清除旧选择，迟到的响应不串项目。
- 待确认明细可保存为部分方案。既有无引用明细、原手填成本和旧快照保持兼容；最多100行，有引用的规范情景输入上限为1MB，无引用保持原150KB限制。
- 保存、读取、编辑、版本冲突及重复保存沿用既有项目审计流。只写情景假设，不创建采购单、调整库存、触达供应商或写真实现金台账。
