第一步 装（5 分钟）
先确认两件事 1. 电脑上已经装了
Obsidian（没有的话去官网 obsidian.md

.zip 压缩包，由你的交付顾问发给你）。
1.1 完全退出 Obsidian（重要）
系统
怎么算「完全退出」
macOS
菜单栏 Obsidian → 退出 Obsidian，或按
Cmd + Q

⚠️ 只关窗口不算退出。安装脚本需要 Obsidian
处于关闭状态，否则装完仍是旧版本。
1.2 解压客户包
双击 .zip 解压（macOS 用「归档实用工具」，Windows
用右键「全部解压缩」）。
⚠️ 不要在压缩包里直接双击运行文件，要先解压出来。
1.3 运行安装脚本
系统
双击这个文件
macOS

一键安装或升级-Windows.bat

你看到的提示

左侧还是没有：命令面板（Cmd/Ctrl + P）搜「知识库状态」，把结果截图发给顾问。

第四步 配一个 AI 引擎（10
分钟，二选一）
为什么必须先配：没配模型时，点「运行」不会有任何反应——这是新人最常踩的坑。
4.1 先选路线
方案
什么时候选
数据去向与费用
本机模型（Ollama）
合同、价格、客诉等敏感资料
数据完全不出本机；免费，但吃本机内存/显存，速度较慢
云端模型（DeepSeek 等）
写稿、整理、分析等量产活
只发送你勾选并确认的来源；按量计费，需自备 API
Key
原则一句话：敏感资料走本机模型，量产写作用云端。
4.2 按路线配置（都在「设置」里）
本机模型：先在本机装好 Ollama 并下载模型 → 设置 → AI
服务商 → 选「本机 Ollama」；
云端模型：设置 → AI 服务商 → 填入 API Key →
选模型（如 DeepSeek）→ 保存。
4.3 试一句
打开右侧 AI 助手，输入「你好」，回车。
✅ 成功标准：能得到回答。
⚠️
云端是按量计费的：先用小额额度试，确认效果再加大。凭据（API
Key、激活码）永远不要写进笔记、不要发给 AI 助手。
第五步
让部门模块页有内容（第一次约 30 分钟）
先理解一句话：模块页是「投影面」——知识库里有几条符合规范的知识，页面上就有几张卡片。空库看到空页是正常的。
5.1 第一步：把笔记放对位置
放这里
会被投影吗
Hotel KnowledgeOS/Approved Knowledge/<部门>/
✅ 会
你原来的正式层目录，如 03_方法库/<部门>/
✅ 会
00_AI Inbox/、_附件/
❌ 不会（故意的：先收后审）
5.2
第二步：给笔记补上「治理字段」（两种办法挑一个）
办法 1 ·
会改文本就用这个（最稳）：把下面这段原样粘到笔记最上方，再改内容：
---
title: 前厅高峰入住交接 SOP
approved: true
allowLocalContentStudio: true
distributionRight: OWNER_ORIGINAL
rightsEvidenceId: EV-2026-001
version: "1.0"
approvedBy: 张经理
approvedAt: 2026-09-24
reviewDueAt: 2027-03-23
module_ids: [FRONT_OFFICE]
knowledge_type: SOP
status: active
---
字段
填什么
approved / approvedBy /
approvedAt
谁、在什么时候审的（写你自己的名字与日期）
version
版本号，改内容就升一版，如 "1.1"
reviewDueAt
到期要重新审的日期（建议 6
个月后）；过期会自动从模块页消失
rightsEvidenceId
权利凭证编号，自己编一个即可
distributionRight
四选一：OWNER_ORIGINAL（你原创）/
HKOS_ORIGINAL（产品方原创）/
LICENSED_FOR_DISTRIBUTION（已获授权）/
CUSTOMER_PRIVATE（仅本店自用）
module_ids
这条知识属于哪个部门模块（写错就等于没写）
knowledge_type
建议
SOP / CHECKLIST / TRAINING / RESOURCE / KNOWLEDGE
办法 2 · 不想手写就用命令：Cmd/Ctrl + P
→ 搜「登记知识来源」（把笔记接入检索）→
①输入路径关键字筛出范围（例 03_方法库/收益管理）→
②看建议值与冲突项（冲突只报告、不覆盖你已有的值）→
③确认应用。
放心用：这条命令只写它自己管的字段，冲突不改，支持一键撤销，撤销后与备份逐字节一致。
✅ 成功标准：回到「前厅」等模块页，出现带
SOP · v1.0 · 审核：××× · 复审：2027-03-23 的卡片。

8.1
版本更新（不用你管，但知道在哪看）
插件每次启动 Obsidian
会自动检查更新，通道默认「日常更新通道」，不用改；
当头像左侧出现蓝色胶囊「更新已就绪 v1.3.60 ·
重启后自动安装」时，说明新版本已经下载好并验签通过了：
什么都不用点，正常退出
Obsidian、下次再打开，就自动装好了；
想马上装：退出 Obsidian 再打开一次即可；
不强制、不打断你工作，笔记和知识库内容永远不会被更新覆盖（更新只替换插件程序文件）。
想手动装最新版：下载最新安装包 → 重跑安装脚本（笔记不受影响）。
✅
成功标准：重启后打开「设置」，插件版本号已变成新版本号（例：v1.3.60）。
8.2 备份（每周一次）
最小备份：把整个知识库文件夹复制一份到移动硬盘（含
Hotel KnowledgeOS/ 与各目录）；
推荐：把知识库做成 git 仓库，每周提交一次（还能给
AI 写入留回滚点）；
⚠️
不要只备份插件目录：插件是程序、可以重装；知识库才是你的资产。
8.3 恢复
关闭 Obsidian；
把备份的知识库文件夹复制回原位（覆盖）；
打开 Obsidian，工作台应能读到原有笔记、审批状态与头像；
界面异常时：命令面板搜「恢复诊断」跑一次只读自检，再搜「知识库状态」查看库与授权状态。
8.4 换电脑
新电脑按第一步装好插件；
把知识库文件夹整体拷过去；
设置 → 本机绑定 →
走换机流程重新绑定（原机器的绑定失效，激活码不变）；
在新机器上重新填一次 AI 服务商的 API Key。
8.5 卸载
删除知识库下的
.obsidian/plugins/yusheng-hotel-knowledge-os/
目录即可（或先在 Obsidian 设置里关掉插件再删）。
卸载不影响你的笔记。卸载前建议留一份备份，并记下激活码。
