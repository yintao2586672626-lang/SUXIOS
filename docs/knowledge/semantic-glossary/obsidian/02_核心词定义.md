# 核心词定义

- **ADR**：平均每日房价；在OTA范围内只计算OTA ADR，必须使用同平台、同日期和同口径房费收入除以间夜，任一输入缺失或间夜为零时不可计算。（分类：`metric_alias`，metric：`adr`，route：`revenue-research-center`）
- **详情页访客**：携程酒店详情页访客概念；必须绑定携程具体模块、口径和严格回读事实，不能与美团商详访客直接混用。（分类：`metric_alias`，metric：`ctrip_detail_visitors`，route：`ctrip-ebooking`）
- **列表页曝光人数**：携程数据中心列表页去重曝光人数；单位为人，不等同于展示次数或广告 impressions。（分类：`metric_alias`，metric：`ctrip_exposure_users`，route：`ctrip-ebooking`）
- **曝光到访率**：曝光阶段到详情访问阶段的转化率；分子分母必须来自同酒店、同平台、同日期和同口径漏斗，缺失时不可计算。（分类：`metric_alias`，metric：`exposure_to_visit_rate`，route：`online-data`）
- **曝光量**：OTA页面被展示的次数概念；与曝光人数不是同一口径，只有同酒店、同平台、同日期、同来源定义且严格回读后才返回数值。（分类：`metric_alias`，metric：`ota_exposure_volume`，route：`online-data`）
- **意向支付转化率**：意向或订单填写阶段到支付阶段的转化率，属于更靠后的漏斗阶段；不能与曝光到访率合并。（分类：`metric_alias`，metric：`intent_payment_conversion_rate`，route：`online-data`）
- **商详访客数**：美团酒店商详页访客概念；只在美团同口径事实内映射，不能替代携程详情页访客。（分类：`metric_alias`，metric：`meituan_detail_visitors`，route：`meituan-ebooking`）
- **曝光人数**：美团实时流量漏斗中的去重曝光用户数；来源 exposureUV，单位为人，不等同于曝光量或展示次数。（分类：`metric_alias`，metric：`meituan_exposure_users`，route：`meituan-ebooking`）
- **OCC**：入住率或出租率；必须使用同范围出租房夜除以可售房夜，分母缺失或为零时不可计算。（分类：`metric_alias`，metric：`occ`，route：`revenue-research-center`）
- **RevPAR**：每间可售房收入；必须使用同范围房费收入除以可售房夜，缺少任一输入时不可计算。（分类：`metric_alias`，metric：`revpar`，route：`revenue-research-center`）
- **间夜量**：在同一平台和日期归属口径下的销售或出租间夜数。（分类：`metric_alias`，metric：`room_nights`，route：`revenue-research-center`）
- **客房收入**：已映射且同业务日期口径的房费收入；不得用订单GMV、支付额、结算额、押金或挂账替代。（分类：`metric_alias`，metric：`room_revenue`，route：`revenue-research-center`）
- **Obsidian**：外部可阅读的来源、索引、定义和关系导航层；不是永久模型训练，也不是实时酒店经营数据库。（分类：`personal_common`，metric：`null`，route：`knowledge-center`）
- **Openness**：用户个人语境中的专用词；具体含义以当前对话为准，不映射酒店指标、宿析OS功能或经营事实。（分类：`personal_common`，metric：`null`，route：`null`）
- **Typeless**：个人输入识别与词典工具语境；维护说明和导入出处在宿析OS知识中心检索，不代表酒店指标或系统内置经营功能。（分类：`personal_common`，metric：`null`，route：`knowledge-center`）
- **酒店AI工具箱**：宿析OS内受控智能工具与问答入口。（分类：`suxios_system`，metric：`null`，route：`agent-center`）
- **智能能力配置**：查看和测试宿析OS智能能力配置的入口。（分类：`suxios_system`，metric：`null`，route：`ai-model-config`）
- **自动采集设置**：配置和查看授权数据采集计划的系统入口；词条本身不触发采集。（分类：`suxios_system`，metric：`null`，route：`online-data`）
- **自动化运行监控**：查看自动化调度、运行和失败记录的系统入口。（分类：`suxios_system`，metric：`null`，route：`automation-monitor`）
- **携程数据**：携程渠道数据、采集状态和经营画布入口；仅代表携程渠道范围。（分类：`ota_ctrip`，metric：`null`，route：`ctrip-ebooking`）
- **AI日报**：基于当前严格证据生成、预览和人工发送经营日报的入口。（分类：`suxios_system`，metric：`null`，route：`ai-daily-report`）
- **今日经营工作台**：宿析OS日常经营工作的起始页面与任务总览入口。（分类：`suxios_system`，metric：`null`，route：`compass`）
- **数据健康**：查看来源、采集、保存、回读、缺失和失败状态的入口。（分类：`suxios_system`，metric：`null`，route：`online-data`）
- **数据配置**：配置系统数据源和采集设备的入口；不代表数据已经可用。（分类：`suxios_system`，metric：`null`，route：`data-config`）
- **AI决策审计**：查看AI建议证据、置信、人工确认和失败记录的入口。（分类：`suxios_system`，metric：`null`，route：`ai-governance`）
- **知识中心**：宿析OS内可追溯知识单元、来源和检索入口；参考资料不自动成为经营事实。（分类：`suxios_system`，metric：`null`，route：`knowledge-center`）
- **美团数据**：美团渠道数据、采集状态和经营画布入口；仅代表美团渠道范围。（分类：`ota_meituan`，metric：`null`，route：`meituan-ebooking`）
- **企业微信通知**：企业微信通知配置和人工发送入口；识别词条不构成发送授权。（分类：`suxios_system`，metric：`null`，route：`wechat-notification`）
- **任务执行与复盘**：人工确认后的运营任务、执行证据和复盘入口。（分类：`suxios_system`，metric：`null`，route：`ops-track`）
- **PMS经营数据**：PMS或全酒店经营事实入口；不能用OTA渠道数据替代。（分类：`suxios_system`，metric：`null`，route：`pms-operating-data`）
- **收益分析中心**：在已验证事实范围内查看收益分析、经营问答和证据缺口的系统入口。（分类：`suxios_system`，metric：`null`，route：`revenue-research-center`）
