# JHIRA V2.8 网站学习与宿析OS适配结论

本次完成范围是授权可见页面学习、机制拆分、样例验算和参考知识入库。资料处置为store_only，能力为absorption_candidate，未完成业务功能正式吸纳。来源：[JHIRA授权页面](https://joydo.us.ci/index.full)，2026-10-01，合作伙伴角色。

## 最值得保留的方法

**经营保本、偿债后的现金保本、目标回本必须分别展示。** 设可售间夜A、已售間夜Q、到手房价p、每已售间夜成本v、月固定成本F、债务现金支出D、剩余未回收投资I、目标月数T：

- Q=A×出租率；到手营收=Q×p；贡献毛利=Q×(p-v)。净房价口径下佣金不能重复扣除；含佣金平台价与净价必须明确转换条件。
- 经营保本出租率=F/[A×(p-v)]。偿债现金保本再加入实际本金、利息及其他现金调整，避免利息重复扣除。
- 在简化稳定月度模型中，目标回本出租率=(F+D+I/T)/[A×(p-v)]。目标年限是约束条件，不改写收益事实。
- 所需出租率超过100%即当前假设下不可达；贡献毛利非正、分母为零、必要输入缺失或净现金流非正时不能输出有限正回本期。
- 合同余量=真实剩余合同期−同口径预计回本期；测算年数不是合同年数。实际投资者收回与假设经营现金回本必须继续分开。

这些是通用算术和适配建议，不是对网站隐藏实现的复刻。30天仅用于重放来源样例；实际月份应使用对应日期的有效房量/可售间夜。季节性、爬坡、税费、维护资本支出、营运资金和退出现金必须明确有无。

## 拆分后的三个参考单元

| 单元 | 保留的机制 | 当前证据与不适用边界 |
| --- | --- | --- |
| 现金流和回本目标 | 房价口径、固定/变动成本、经营/偿债/回本分开、不可达及合同余量 | 来源样例可独立验算；非零债务、耗用系数及完整财务模型未验证；候选未接入 |

| 报告证据准备度 | 参数与证据快照→预览→人工复核→导出；记录缺口与共享字段口径 | 实际预览可见，复核2/6且六个格式下载入口仍禁用；没有导出一致性证据 |

## 与既有宿析OS能力的去重

本地源码已经有InvestmentScenarioCalculator的固定/变动成本、利润/现金代理、盈亏平衡和九格敏感性；InvestmentScenarioService有preview/save/detail和回读；InvestmentPaybackCalculator保留实际投资者现金台账；InvestmentDecisionSupportService有投决证据门禁。以上只是本次定向源码证据，不是页面、远端或部署验收。

因此不重复创建计算器、投资模块或知识库。最有价值的增量候选是：在既有情景模型中明确净房价口径，增加目标回本所需出租率及真实合同余量；用品明细可以汇总到既有每间夜成本。正式实现之前还需确认融资口径、输入保存和页面回读的兼容方案。既有JHIRA资料是报告展示仓库参考，本次网站来源不同，以新稳定键储存，不覆盖旧资料。

## 保留而不采纳的内容

成本档位、耗用比例、风险分数、阈值、推荐价格与出租率均为来源特定样例，不进入业务默认值。排名不是曝光/转化/订单事实；未知排名不能算零或自动输出整改。示例酒店不映射到宿析酒店。来源的标准库、知识库、专家库与管理中心在本角色未可见。
