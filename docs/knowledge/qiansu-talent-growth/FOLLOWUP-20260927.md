## 缺陷复现与修复

父级 `ManagerCapabilityPanel` 原先立即更新选择的人员/酒店，却保留上一份 `profile`，直至新请求返回。带教子组件因此可能用新人员 ID 展示上一人员的案例与权限。服务端的范围校验不能消除前端这一短暂的错误展示。

先在隔离 SQLite 中使用真实父组件、真实控制器复现，再修改 `public/components/system/app-main-components.js` 的 `loadProfile()` 和 `load()`。复现断言失败为 `Previous manager case/permissions must disappear while the next profile is loading`；修复后延迟人员请求和酒店请求时，旧带教组件均立即消失。

目标文件已有其他工作内容，本次只增改档案重置与队列请求作废逻辑。生成资源通过项目构建脚本更新。
