## 可以直接参考的 SOP 空模板

```text
名称：
适用酒店、岗位、平台与场景：
触发条件：
必要资料与前置条件：
标准动作：步骤 / 负责人 / 输出 / 完成证据
异常处理：缺资料 / 执行失败 / 超出权限时的处理方式
不可接受情况：由本店负责人确认
来源章节与版本：
审核人、审核日期、复审日期：
```

没有确认的地方填“待确认”，不要照搬示例里的经营参数。该空模板使用 HKOS 的场景与动作结构，并由宿析补充负责人、完成证据和异常分支。

## 可以直接参考的案例复盘空模板

```text
案例范围：酒店 / 岗位 / 时间 / 平台 / 资料来源
问题与证据：看到什么 / 哪些仍不确定
处理过程：动作 / 负责人 / 记录
结果：完成证据 / 观察到的变化 / 未验证部分
复用条件：适用情况 / 不适用情况
候选改进：建议修改的 SOP / 待审核负责人
```

字段为宿析对来源“案例与复盘”方法的适配。一次结果不能直接证明因果或对其他门店有效。

## 六段式内容制作空模板

1. **选题卡**：受众、要回答的问题、主题和场景。
2. **证据卡**：来源编号、版本、原文位置、待核对内容。
3. **脚本主版**：基于证据写草稿，保留引用，缺内容处标注待填写。
4. **平台改编**：保持事实一致，调整篇幅和表达。
5. **素材与拍摄简报**：图片、画面、权利范围和负责人。
6. **发布包与复盘**：审核记录、发布范围、后续表现；发布动作另行授权。

## 知识审核与复审清单

- 保留原始材料与出处，新材料进入待整理状态。
- 核对适用场景、版本、使用范围、负责人和证据。
- 有权审核人员核实内容后记录审核日期和复审日期，缺信息保持待核验。
- 引用时核对版本；到期、撤销或来源变化后重新审核。
- 保留草稿和历史版本。此清单是流程参考，不会自动审批任何门店制度。

## AI 成果验收清单

- 目标和产物是否明确，来源范围是否有限且可追溯。
- 缺失资料是否标注待补充，是否出现无来源结论。
- 任务记录与成果是否分别保存，状态是否符合实际。
- 来源、结论和适用范围是否经人核对。
- 重新打开成果后，内容是否与保存前一致。
- 来源改变后，是否重新检查受影响成果；草稿完成不等于现场执行完成。
