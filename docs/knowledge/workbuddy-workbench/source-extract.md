# 来源中可直接观察的方法表述

1. “一句话提需求，不用写长提示词。把‘你是谁、每天管什么、一屏想看哪几块’说清楚就行。”
2. “想不清楚就让它反过来采访你。发一句‘你反过来采访我，每轮最多问 3 个问题’。”
3. “大任务拆开分批发，高频提示词存进素材库重复调用，关掉不必要的智能美化。”

# 来源案例声称

- 来源称有人把孕期管理、月度汇报、投资知识蒸馏和日常业务资料放入个人工作台。
- 来源称央企月度汇报由 2 小时缩短到 15 分钟，桌面文件由 60 多个减少到 4 个分类文件夹，并提到积分消耗和每日签到。

这些案例、效率数字、产品模板、专家能力、积分规则、移动端部署和公开分享均未在本次任务中独立验证，只能作为来源声称保存，不能成为宿析OS效果、成本、产品能力或经营事实。

# 本次允许学习的最小机制

```text
模糊工作台需求
  -> 先问角色
  -> 再问每天反复处理的真实任务
  -> 再问首屏最想看到的结果
  -> 只组合系统已有可信入口
  -> 缺信息时继续澄清，不生成虚构页面、数据或完成状态
```

宿析OS按项目协作合同将“每轮最多 3 个问题”收紧为“每轮只问 1 个决定性问题，最多 3 轮”。
