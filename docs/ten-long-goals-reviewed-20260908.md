# 十项长目标统一候选验收记录

本次将 OTA 数据到经营动作、效果复核的十项功能放入同一候选，补齐保存、精确回读、旧数据兼容与失败状态。发布候选继承此前 OTA 修复与预测工作台的已审核提交，并完成跨模块依赖核对。

| 目标 | 用户可用结果 | 本轮重点复核 |
|---|---|---|
| 01 OTA 采集恢复 | 识别采集、入库、回读各阶段缺口并恢复任务 | 服务端从原始回执独立核对来源；修改采集方式标签不能绕过证明 |
| 02 收益经营底账 | 按同酒店、渠道、日期和口径核对金额与差异 | 期间口径冲突时禁止归因为手续费或退款；保留已有逐日观察 |
| 03 中文精准查数 | 澄清歧义、期间查数、保存与按编号追问 | 日期缺失显示部分覆盖；历史内容按精确摘要回读 |
| 04 AI 经营报告 | 展示事实、分析与依据并连接后续运营 | 证据范围与报告保存一致；缺证时保持缺失 |
| 05 预测与定价工作台 | 回放预测、保存方案、分页找回早期版本 | 拒绝凭证形态标识；失败按操作区分；未观察日期计入训练缺口 |
| 06 任务执行与复盘 | 保存条件、执行核实、观察结果与历史 | 条件按无重复的完整集合校验；任务完成与效果成立分开 |
| 07 推广回报与实验 | 手工记录推广账面回报及实验版本 | 延迟文件读取不能污染刚恢复的历史；缺证不输出增量收益 |
| 08 知识适用性与修订 | 按范围检索、修订并查看受影响问题 | 顶层与嵌套限制取交集；幂等重试保留影响清单；过期请求失效 |
| 09 投资与经营测算 | 分段经营假设、敏感性、保存并精确回读 | 保留计算精度至展示阶段；亏损不因提前四舍五入变成盈利 |
| 10 日常工作入口 | 经营状态、查数、采集恢复、任务核实、效果复盘 | 完整页面串联；切换范围后不能串用其他酒店、日期或历史 |

- Node 功能与前端合同：540 项测试通过。

- 完整页面五流程通过，页面异常为 0；桌面与 390px 窄屏覆盖，查数和复盘均完成精确历史回读。以响应事件控制迟到返回，并逐场景重置范围，保留严格失败断言；原有固定等待造成的串联失败已有记录。
- GitHub 精确提交检查与合并结果以 PR 状态为准。

## 后续主线整合与前端合同复核

第二轮候选的 GitHub 后端及数据库检查通过：6,033 项、57,580 条断言，6 项跳过。Node 检查指出导航位置和首页权威说明已变化，定向断言现与实际入口一致，并继续要求权威核验组件可达、专业诊断不能冒充闭环结论。

同步主线 PR #46 时，保留手工采集独立请求序号及失败恢复的完整范围检查，同时保留历史排名回读状态。真实清理函数释放旧请求但不能释放其他任务的加载状态；不同酒店、账号、日期、平台、同酒店替换请求和迟到恢复回归共 96 项通过。主线租约恢复的 18 项、72 条断言通过。

生成文件只作为官方构建入口的种子，随后按合并后的源重新生成；启动资源版本链同时覆盖收益、运营、知识和模拟模块。保留主线更严格的美团 5,000 行与采集服务 6,368 行限制，以及本候选更严格的路由 767 行限制。最终精确提交的全量检查以 PR 中的结果为准。

第三轮后端 6,044 项 / 57,619 条断言通过，6 项跳过。干净 Node 作业暴露底账 UI 测试跨作业依赖本地 output 的问题；现每次通过真实证明、独立 SQLite 保存及精确回读生成专属临时模型，并按系统选择已有 Edge 或 CI 安装的 Chromium。底账 35 项 / 462 条断言、导出及桌面/手机页面 2 项通过，测试不再读取旧输出作为输入。

第四轮完整 Node、OTA→收益→运营业务链及完整页面切换通过，后续审批旅程发现 mock 缺失正式 execution-flow 接口的 capabilities.hotel_id，页面因此正确拒绝不明范围。独立静态服务复现同一失败；补齐接口原有身份合同后，4 条审批/精确恢复旅程与 12 条范围隔离回归通过。另核验定位请求携带酒店和意图编号，不放宽生产范围检查。

第五轮业务链捕捉到快速切页的真实取消误报：loadOnlineDataList 未识别 AbortError，且同参数新页面可能复用上一页的在途 promise。修复将页面/会话策略纳入在途请求和加载归属，保留结果缓存与同代去重，真实失败仍报告。提取实际函数的新增测试先 7 失败/6 通过，修后 13 项及原生命周期 25 项通过；直接前端依赖 110 项通过。严格业务链错误断言保持，入口资源已由正式脚本重建。

## 证据边界

页面与持久化实验使用明确标注的合成数据、临时 SQLite 和真实目标服务。辅助 API 不在测试范围时显式返回未实现状态。自动化与静态合同通过，不等同于生产部署、真实 OTA/PMS 账号验证、真实资金效果或 LLM 效果证明。尚缺完整源记录的事实继续保持 blocked / missing，不补零、不借旧数据、不扩大为全酒店结论。

本次包含三条新增迁移的校验登记；生产迁移与部署需另行执行。冻结旧工作区及其他并行工作的源文件不属于本次发布输入。
